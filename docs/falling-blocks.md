# 落下ブロック

砂（`sand`、状態 ID 7）と砂利（`gravel`、状態 ID 42）は、真下の支えを失うと落ちる。レジストリの `falls = true` で指定し、全面が固体の立方体にだけ設定できる。

採掘・設置・爆発・流体や植物の変化などでブロックが変わると、変更したマスとその真上を調べる。変更したマスが落下ブロックで真下が空いている場合、または変更したマスが空いていてその真上が落下ブロックの場合に、落下ブロックの位置を 2 tick 後に予約する。空きは空気、水、溶岩（水と溶岩は源と流れの両方）。花、作物、たいまつ、半ブロック、柵などは支えになる。生成や読み込みだけでは新しい予約を作らないため、地形にできた空洞の上の砂や砂利は、真下のマスが変わるまで浮いたままになる。

予約の時刻に真下が空いていれば、ブロックを 1 マス下へ移し、元のマスを空気にする。移動先には 2 tick 後の予約を入れ、支えがあればそこで止まる。積み重なったブロックは、下のブロックが移動して元のマスが空くたびに順に落ちる。移動先の水や溶岩は消え、周囲の流体は既存の規則で流れを計算し直す。ワールドの下端を越える場合はブロックが消える。

落下は両ゲームモードで同じ。プレイヤーや Mob がいるマスにもブロックを置き、窒息は既存の判定に従う。アイテムが埋まった場合は既存の処理で上へ押し出す。落下自体でアイテムは発生せず、サバイバルで砂を採掘すると従来どおり砂のアイテムが落ちる。

途中の状態も通常のブロックなので、[スケジュール tick](water.md#スケジュール-tick)の予約と一緒にチャンクへ保存され、読み込み後に続きから落ちる。既存の仕組みで処理順序と保存を扱え、新しいエンティティの種類や通信、専用の描画を追加する必要がない。クライアントはサーバーから通常のブロック更新を受け取り、1 マスずつの移動を表示する。なめらかな補間や落下時の効果音はない。
