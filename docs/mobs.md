# Mob と牛

サーバーが `BTreeMap<u32, Mob>` を持ち、ID 順に処理する。落ちているアイテムと同じ `next_entity_id` を使う。最初の種類は `MobKind::Cow = 0`。位置は足元の中心で、牛の当たり判定は幅 0.9 ブロック、高さ 1.3 ブロック。重力、衝突、小さな段差の上り方、ジャンプと遊泳にはプレイヤーと同じ物理を使う。歩行入力は `forward = 0.5` で、平地の定常速度は約 0.108 ブロック/tick（約 2.16 ブロック/秒）。

状態ハッシュには、牛がいるときに件数と、ID 順に種類、位置、速度、向き、年齢、接地・遊泳・ジャンプの状態、歩行目標と残り時間・連続停止回数を加える。⑦-2a では逃走目標・残り時間・連続停止回数と、落下開始高、溶岩・窒息の間隔カウンタも加える。牛が 0 頭のときは、牛の状態ハッシュには何も加えない。

## 歩き回り

- 止まっている牛は毎 tick、1/120 の確率で歩き始める。seed、牛の ID、`game_time` を整数ハッシュにかけ、用途別の値から方向と距離を選ぶ。乱数の内部状態は保存しない。
- 水平目標までの距離は最大 8 ブロック。歩きながら目標の方向へ向きを合わせる。yaw は度で 0 が +Z、90 が −X。
- 目標の 0.5 ブロック以内に入るか、100 tick 経過するか、ジャンプで上昇中の tick を除き、水平移動が 0.01 ブロック未満の tick が 2 回続いたときに止まる。
- 0.7 ブロック先の列を調べ、落差が 4 ブロック以上か、足元や体の進行先に溶岩があれば止まる。段差の上に空間があれば、物理の自動段差上りを超える 1 ブロックまでの段差でジャンプする。水の中ではジャンプ入力を入れて水面付近に浮く。

## 出現と消滅

- 400 tick（20 秒）ごとに、参加済みプレイヤーを ID 順に処理する。水平 64 ブロック以内に牛が 8 頭未満なら、プレイヤーの ID と時刻を使用した整数ハッシュで、水平 24〜48 ブロックの範囲から群れの中心の列を一度選ぶ。
- 中心の列はチャンクがメモリにあり、その列の最上部の固体が草ブロックで、直上 2 マスが空気で、ほかのプレイヤーから水平 24 ブロック以内に入らないことが条件。条件を満たせば、中心を含め 1〜3 頭を試みる。残りの候補は中心から水平 2 ブロック以内の異なる列を使い、同じ条件とプレイヤーからの距離を調べる。無効な列は飛ばす。8 頭の上限は出現を試すプレイヤーから水平 64 ブロック以内で判定する。別のプレイヤーの周りでは、この出現によって 8 頭を超えることもある。
- サバイバルとクリエイティブの両方で、昼夜や明るさに関係なく出現する。
- 参加済みのどのプレイヤーからも水平 128 ブロックより遠いか、チャンクがメモリにないか、足元が `health::VOID_Y`（−128）を下回る牛は消える。
- `Server::tick` のアイテム処理後に、出現、AI と物理、消滅の順で処理する。牛はワールドやチャンクの保存データに含めないため、ワールドを開き直した場合やチャンクが読み込み解除された場合は、その後の出現判定で新しい牛が現れる。

## 体力と攻撃

牛の体力は 10。参加済みで生存中のプレイヤーは、目（足元から 1.62 ブロック上）から牛の当たり判定（幅 0.9、高さ 1.3）の最も近い点まで 8 ブロック以内なら攻撃できる。サーバーは tick の先頭でパケットを受信順に処理する。

| 手に持っているもの | ダメージ |
| --- | --- |
| 素手、道具以外 | 1 |
| 斧 | tier + 2 |
| つるはし | tier + 1 |
| シャベル、鍬 | tier |

tier は `items.toml` の `tool.tier`（木 1、石 2、銅 3、鉄 4）。ダメージはゲームモード共通で、サバイバルではダメージが通るたびに疲労が 40 増える。

ダメージが入った tick に無敵時間は 10 tick になり、以後は tick の先頭で 1 ずつ減る。残り時間がある間はダメージとノックバックを受けない。残り 0 になった tick から攻撃が再び通る。

ノックバックは攻撃者の足元から牛の足元へ向かう水平速度 0.4 で、元の水平速度を置き換える。水平位置が同じ場合は、サーバーが最後に受理した攻撃者の yaw の向きを使う。牛が接地していれば上向きの速度も 0.36 にする。牛は歩行をやめて `Wander::Idle` に戻り、無敵時間中は新しい歩行を始めない。（⑦-2a で変更。下の節を参照）

体力が 0 になると牛が消えてアイテムを落とす。牛がダメージを受けるのはプレイヤーの攻撃だけ。落下や溶岩では体力は減らない。（⑦-2a で変更。下の節を参照）

## 環境からのダメージ

- 毎 tick、移動後に落下、窒息、溶岩の順で判定する。牛の当たり判定で着地を検出し、落下の最高点から着地までの高低差を切り捨てて 3 を引く。結果が正ならその分だけダメージを受ける。足元が流体に入ると落下の記録を消す。
- 頭（足元から 1.1 ブロック上）が不透明な 1 マス全体のブロックに埋まると、10 tick ごとに窒息で 1 ダメージを受ける。足元から 0.4 ブロック上か頭に溶岩があると、10 tick ごとに 4 ダメージを受ける。
- 攻撃と環境ダメージは同じ 10 tick の無敵時間を使う。無敵中も落下の追跡と間隔の計測を続け、その間に発生したダメージは破棄する。環境ダメージにノックバックはない。
- 牛は溺れない。足元が奈落の消滅高度を下回ると、アイテムを落とさず消える。
- 溶岩で死亡したときは、精錬レシピのあるドロップをその出力（生の牛肉なら焼いた牛肉）に置き換える。個数の決め方は共通で、レシピのないアイテムはそのまま落ちる。

## 逃げる

- ダメージを受けて生き残った牛は 60 tick 逃げる。再びダメージを受けると、残り時間を 60 tick に戻して目標を選び直す。
- 攻撃を受けると攻撃者から離れる水平方向を選ぶ。水平位置が同じ場合と環境ダメージの場合はランダムな方向を選ぶ。目標までの距離は 5〜8 ブロックで、0.01 ブロック刻み。
- 逃走の前進入力は `forward = 0.75`。段差でのジャンプや水中での動きは歩行と同じ。攻撃を受けた tick はノックバックを処理し、次の tick から逃走の前進入力を入れる。環境ダメージの場合も、逃走の前進入力は次の tick から入れる。
- 目標に着くか、崖や溶岩で進めないか、水平移動が 2 tick 続けて 0.01 ブロック未満になると、ランダムな目標を選び直す。停止回数にはジャンプで上昇中の tick を含めない。新しい目標への前進入力は次の tick から入れる。逃走時間が尽きると `Wander::Idle` に戻る。

## ルートテーブル

`data/registry/loot.toml` の `[[loot]]` に `mob`、`item`、`min`、`max` を指定する。未知の Mob 名やアイテム名、`min > max` はビルド時にエラーになる。

牛の項目は生の牛肉（`raw_beef`）1〜3 個。ワールドの seed、牛の ID、死亡時の `game_time`、項目番号を使った整数ハッシュから、両端を含む範囲内で個数を決める。個数が 0 の項目は出現しない。牛の中心（足元から 0.65 ブロック上）に、採掘のドロップと同じく拾得待ち 10 tick のアイテムを生成する。生の牛肉はかまどで焼いた牛肉（`cooked_beef`）になる。

## プロトコル13

複数バイトの値はビッグエンディアン。

| 方向 | 番号 | パケットと本体 |
| --- | --- | --- |
| S2C | 0x0d | `MobSpawn` — id u32、kind u8（牛は 0）、x/y/z f64、yaw f32 |
| S2C | 0x0e | `MobMove` — id u32、x/y/z f64、yaw f32 |
| S2C | 0x0a | `EntityRemove` — id u32。アイテムと共通 |

アイテムと同様に、クライアントへ送信済みの `sent` チャンクにいる牛だけを同期する。可視範囲に入ったら Spawn、位置または向きが変化したら Move、範囲から外れるか消滅したら Remove を送る。

## プロトコル14

| 方向 | 番号 | パケットと本体 |
| --- | --- | --- |
| C2S | 0x10 | `Attack` — id u32 |
| S2C | 0x0f | `MobHurt` — id u32 |

牛が攻撃を受けて生き残ったとき、すでにその牛の `MobSpawn` を受け取ったクライアントへ `MobHurt` を送る。死亡時は `EntityRemove` を送る。Wasm は牛ごとに最後の `MobHurt` の受信順を保持し、`window.__mc.stats().mobs` の `hurt` で読める。まだ攻撃を受けていない牛の値は 0。⑦-2a からは、環境ダメージを受けて生き残ったときも同じクライアントへ `MobHurt` を送る。

## クライアントと E2E

Wasm は現在と前回の位置、ID、種類、向きを保持する。TS はアイテムと同様に 50 ms で位置を補間し、同じライトマップと霧を使う。牛は胴、頭、4 本の脚からなる 6 箱で、向きに合わせて回す。脚は水平移動中に対角の組で前後に振る。白地の黒いまだら、ピンクの鼻、ひづめの絵は `textures.ts` で生成する。

`window.__mc.stats().mobs` で確認できる。`pnpm test:e2e` の `mobs()` はクリエイティブの Flat ワールド（seed 2026、view 4）を開き、最大 60 秒待って出現を確認する。同じ牛の移動と、ほかの牛が対象の近くやカメラとの間にいなくなるのを待つ。撮影時に対象の向きを確認し、スクリーンショットの鼻が映る範囲で色を調べる。

左クリックでは、カメラの視線と補間後の牛の当たり判定との交点を 5 ブロック以内で探す。最も近い牛がブロックより手前にいれば、牛を攻撃し、ブロックの枠線を隠す。左ボタンを押し続けると 250 ms ごとに攻撃する。サバイバルでは、採掘中に照準が牛に移ると採掘を中断する。牛を叩いた後は 250 ms が経過すると採掘を再開でき、ブロックを狙ってクリックし直した場合はすぐに採掘を始める。

`MobHurt` を受け取ってから 0.5 秒間、その牛を赤みがかった色で描く。

`mobCombat()` はサバイバルの Flat ワールド（seed 2026、view 4）で牛の出現を待ち、牛の近くから胴に照準を合わせてクリックする。最初の攻撃で `hurt` が増え、繰り返し攻撃すると同じ牛が消えることを確認する。奥にある草ブロックが残り、牛の近くに落ちた生の牛肉 1〜3 個を拾うとインベントリに入ることと、ページエラーがないことも確かめる。

## 決定性の確認

既存の seed 2026・600 tick の台本は `DebugHills`。600 tick を通して牛は 0 頭で、指紋は `7c46257055d8c652`。別途、テスト `herds_spawn_on_the_400th_tick_in_both_modes_and_repeat` では、Flat の seed 2026 でスポーン地点にプレイヤー ID 1 を表示距離 4 で参加させ、チャンクの要求を先に処理する。この条件で 400 tick に 3 頭が出現する。ID 順に足元座標は `(45.5, −60, 2.5)`、`(46.5, −60, 1.5)`、`(46.5, −60, 2.5)`。600 tick までに移動し、サバイバルとクリエイティブで同じ位置になることを確認する。
