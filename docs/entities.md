# エンティティ、ドロップと拾得

ワールドが `BTreeMap` でエンティティを所有し、ID昇順で移動・拾得・通知を処理する。種類は拡張可能な enum。位置は箱の底面中心、速度はブロック/tick。時刻・環境に依存せず、ドロップの乱数はワールドの seed と次のエンティティIDから `JavaRandom` を作る。浮動小数点は基本演算、floor、sqrt で計算する。

| 基盤 | 値 |
| --- | --- |
| ID | u32、開始1、単調増加、再利用しない |
| アイテムの種類番号 | 0 |
| 箱の幅・高さ | 0.25 / 0.25 |
| tick 周波数 | 20 Hz |
| アイテムエンティティ上限 | 1024 |
| 寿命 | 経過6000 tick（5分）で消去 |
| 奈落の消去条件 | y < MIN_Y − 64 |

状態は種類、位置、速度、アイテムID、個数、経過tick、拾得待ちtick、接地フラグ。状態ハッシュは次のIDと件数、およびID順に全フィールドを含める。チャンクがメモリにない間は移動・年齢・拾得待ちを進めず、合体と拾得も行わない。メモリからチャンクを読み込み解除すると、そのチャンクのエンティティを消す。**エンティティは保存しない。保存は後のPRで実装する。**

パケット適用とチャンク送信のあと、重力、衝突解決、減衰を行う。衝突はプレイヤーと同じ `physics::resolve` とブロック形状を使い、止められた軸の速度をゼロにする。下向きの移動が止められると接地する。箱が固体に重なる間は、通常の衝突解決をせず上へ押し出す。ワールドの上下限の外は空気として落下できる。

| 運動・合体 | 値 |
| --- | --- |
| 重力 | 毎tick、y速度から0.04を引く |
| y速度の減衰 | 0.98倍 |
| 横速度の減衰（接地 / 空中） | 0.6 / 0.98倍 |
| 埋まり時の上昇 | 毎tick 0.1 |
| 合体の間隔 | ワールド時刻が10 tickの倍数になるtick |
| 合体の距離 | 各軸の差が0.5以下 |
| 合体候補 | 同じアイテムの1ブロック格子と隣接格子。満杯スタックは比較しない |
| 合体の比較数上限 | 1回4096組。小さいID順に比較し、上限でその回を打ち切る |
| 合体の個数 | 合計がアイテムのmax_stack以下のときだけ |

合体は同じアイテムを小さいIDへまとめる。経過tickと拾得待ちは大きい方を引き継ぎ、寿命の延長や拾得待ちの短縮を防ぐ。上限を超える生成では最小IDのものから消す。

Survivalのブロック破壊は対応アイテムをドロップする。Creativeの破壊はドロップしない。`DropItem` は両モードで選択枠から取り出す。空の枠は何もせず拒否数も増やさない。参加前の操作と非有限の方向は拒否する。

| 生成・拾得 | 値 |
| --- | --- |
| 破壊時の個数 | 1 |
| 破壊時の位置 | (x + 0.5, y + 0.25, z + 0.5) |
| 破壊時の横速度 | 各軸 −0.05〜0.05 |
| 破壊時のy速度 | 0.1 |
| 破壊時の拾得待ち | 10 tick |
| 捨てる個数 | 1 |
| 捨てる位置 | プレイヤーの足元からy + 1.3 |
| 方向の正規化 | 長さが1を超えれば長さで割る。長さ0はゼロベクトル |
| 捨てる速度 | dir × 0.3、さらにy + 0.1 |
| 捨てるときの拾得待ち | 40 tick |
| 拾得範囲の拡張 | プレイヤー箱を横の両側に1.0、縦の両側に0.5 |
| 拾得可能な待ち残り | 0 tick |
| 初期キー | Q（KeyQ） |

生成したtickも移動と待ち時間の減算を行う。毎tick、参加済みプレイヤーをクライアントID順に調べ、拡張した箱とアイテムの箱が重なれば `Inventory::add` する。入った分だけ減らし、残数がなくなれば消す。満杯なら残る。変化したインベントリは既存の集約方式で本人に送る。

## プロトコルとクライアント

既存のパケット番号は変更しない。複数バイト値はビッグエンディアン。新パケットは末尾バイト、ID、種類、アイテムID、個数、有限座標を検証する。Count単体はアイテムIDを持たないためワイヤ形式の上限を検証し、ミラーで該当アイテムの上限も検証する。

| 方向 | 番号 | 内容 |
| --- | --- | --- |
| 共通 | バージョン4 | 以前は3 |
| C2S | 0x06 | DropItem: dir f32 × 3 |
| S2C | 0x07 | EntitySpawn: id u32, kind u8（0のみ）, item u16, count u8, x/y/z f64 |
| S2C | 0x08 | EntityMove: id u32, x/y/z f64 |
| S2C | 0x09 | EntityCount: id u32, count u8 |
| S2C | 0x0a | EntityRemove: id u32 |
| 個数 | 1〜max_stack | Count単体は1〜64 |
| ID | 1〜u32上限 | 0は拒否 |

クライアントごとに最後に見せたID・位置・個数を保持する。tick末尾で、そのクライアントの `sent` にチャンクがあるものだけを対象とし、新規はSpawn、対象外はRemove、既存の位置差分はMove、個数差分はCount。同じIDへの同じ種類の通知はtick内で重複しない。Spawn時はMove/Countを重ねない。チャンクのUnload時のエンティティ消去は**サーバーが同じtick末尾に送るRemove**で行う。再接続時はミラーを空にする。

WASMはID順の一覧（ID・アイテム・個数・現在と以前の位置）とクライアントワールドの空光・ブロック光を公開する。Moveで現在位置を以前位置にコピーする。TypeScriptは受信からの経過時間で補間し、カメラとの差を倍精度で計算してからGPUへ渡す。小立方体は専用パイプラインで描き、地形と同じライトマップ・面の明るさ・霧を使う。回転と上下動は描画だけでコアを変更しない。F3と `window.__mc.stats().entities` で確認できる。

| 描画 | 値 |
| --- | --- |
| 立方体の一辺 | 0.25 |
| 補間区間 | 50 ms、範囲外は端点に固定 |
| 回転角 | 経過ms / 2000（rad） |
| 上下動 | 0.04 + sin(経過ms / 500) × 0.03 |
