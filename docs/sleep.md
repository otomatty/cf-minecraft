# ベッドと睡眠

ベッドで夜を越せる。状態、設置、睡眠、リスポーン、保存とブラウザでの表示をここで決める。

## データ

ブロック `bed` は状態 ID 86 から 8 状態。向き `facing`（north / south / west / east）と部位 `part`（foot / head）の組み合わせで、向きは足から頭へ向かう。順序は階段と同じで、north、south、west、east のそれぞれに足、頭が続く。

形は x, z が 0〜16、y が 0〜9 の箱。当たり判定と選択の形は同じ。`occludes` は false、`opacity` は 0、`solid` は true。採掘は `tool = axe`、`min_tier = 0`、`dig_ticks = 10`。流体は入らず、水にも流されない。

アイテム `bed` は ID 84、`max_stack = 1`、燃料なし。置くとベッドになる。作業台の 3×3 で、上の段に白い羊毛 3 個、その下の段にオークの板 3 個（`["WWW", "PPP"]`）からベッド 1 個。`table_only = true`。

## 見た目

高さ 9/16 の箱を足と頭に 1 つずつ描く。上面は `bed_feet_top` と `bed_head_top`、長い側面は `bed_feet_side` と `bed_head_side`、外側の端は `bed_feet_end` と `bed_head_end`、底面は `oak_planks`。上面を向きに合わせて 90° 単位で回し、長い側面の模様は両側で頭から足へそろえる。対になる半分どうしの接合面を隠す。ブロック選択画面やホットバーのアイコンも、足と頭のブロック面を使う。[テクスチャの切り出し](texture-packs.md#ベッドのテクスチャ)

## 置く、壊す

狙ったマスに足を置き、プレイヤーの水平の向き（yaw）の隣に頭を置く。向きは階段と同じ象限で、足から頭がプレイヤーの前方になる。境界の角度は yaw が増える側の象限を取る。クライアントが送る状態は足の状態で、yaw から決まる足と違う状態は拒否する。サーバーが頭を置く。

足と頭の両方が、空気、短い草、水のいずれかで、読み込み済みかつ建築範囲内のときだけ置ける。足か頭が既存のベッドに重なる位置には置けない。足の真下と頭の真下は、たいまつの支えと同じ上面が全面の固体でなければならない。片方でも条件を満たさなければ設置を拒否し、狙ったマスを既存の訂正で送り直す。クリエイティブでも、置き換えられないマスには置けない。サバイバルではベッドを持っているときだけ置く。置けると 1 個だけ減る。

足か頭を壊すと、もう片方も消える。サバイバルの破壊では、どちらを壊してもベッドを 1 個だけ落とす。クリエイティブでは落とさない。爆発でも両方消え、既存の 1/3 の抽選で、先に処理された半分の結果だけを使い、1 台につき最大 1 個にする。片方だけが残ったベッドは直さない。

## 使う

ベッドはチェストやかまどと同じく、Shift なしの右クリックで使う。Shift を押した右クリックは設置。使える距離と、画面を開いていないことの確認は作業台と同じ。足と頭のどちらを狙ってもよい。足と頭がそろっていないベッドは使えず、リスポーン地点も変えない。死んでいるときと、すでに寝ているときは何もしない。

使えるそろったベッドでは、昼でも夜でも、使ったプレイヤーのリスポーン地点を足の座標にする。初めて設定したときと、別のベッドに変えたときだけ、本人に System で「リスポーン地点を設定しました」と送る。同じベッドの 2 回目は送らない。

そのあとで寝られるかを見る。

- 夜でなければ寝られない。夜はゾンビの出現と同じで、`day_time` を 24000 で割った余りが 13000 以上 23000 未満。本人にだけ「夜にならないと眠れません」。
- ベッドの足の中心から水平に各軸 8 ブロック以内、足の床の高さから上下 5 ブロック以内に、体力のあるゾンビ、スケルトン、クリーパーがいれば寝られない。境界は含む。本人にだけ「近くに敵がいるので眠れません」。
- 同じベッドで別のプレイヤーが寝ていれば寝られない。本人にだけ「このベッドは使われています」。

寝られるときは、そのプレイヤーを寝ている状態にする。位置は動かさない。寝始めた位置を覚えておく。

起きるのは次のとき。

- C2S `StopSleeping` を受けたとき。寝ていなければ何もしない。
- 寝始めた位置から 0.1 ブロックより大きく動く移動を受けたとき。ちょうど 0.1 では起きない。移動そのものはいつもどおり検証する。
- ダメージを受けたとき、死んだとき、切断したとき。
- そのベッドが壊れたとき。
- 朝になったとき。

参加済みで生きているプレイヤーが 1 人以上いて、その全員が寝ている状態が 100 tick 続いたら朝になる。`day_time` を次の 0、つまり次の日の 06:00 にする。計算は `(day_time / 24000 + 1) * 24000` で、負の値も `/time set` と同じく `div_euclid` を使う。その tick で通常どおり 1 進んだあとの `day_time` に対して計算する。全員を起こし、時刻の更新を参加済みの全員に送る。`game_time` は、その tick の通常の +1 以外には進めない。1 人でも寝ていなければ数え直す。生きている参加者がいなくなったときも数え直す。寝ている状態と 100 tick の数えは保存しない。再接続すると起きている。どちらも状態ハッシュに含める。

## 寝ている間の画面と E2E

`Sleeping` を受け取ると「眠っています…」と「起きる」ボタンを表示し、背景を約 1 秒かけて暗くする。移動の予測とブロックへの操作は一時停止する。背景をドラッグすると視点を回せる。「起きる」ボタンか、スニークに割り当てたキー（初期設定は左 Shift）で `StopSleeping` を送る。起床の通知で画面を閉じる。ポインターロックが外れていれば、ゲームメニューから戻れる。リスポーン地点の設定や眠れない理由は、既存のチャットに表示する。`window.__mc.stats().sleeping` で睡眠状態を確認できる。

ブラウザ E2E は真夜中のクリエイティブ Flat で、スポーン地点の地面が届いたらすぐに始める。ベッドの選択と 2 マスへの設置、リスポーン地点設定のチャット、睡眠画面の表示、ボタンでの起床、もう一度寝たあとの朝への移行、昼に使ったときのチャット、ページエラーの有無を確認する。睡眠による朝への移行は最大 20 秒待つ。

## リスポーン

死んだあとのリスポーンで、リスポーン地点があり、その位置にそろったベッドがあり、足の上面 `y + 9/16` から高さ 1.8 の当たり判定がほかのブロックの衝突形状と重ならないなら、足のマスの中心 `[x + 0.5, y + 9/16, z + 0.5]` に出す。

そうでなければ、リスポーン地点を消してワールドの初期スポーンに出し、本人にだけ「ベッドが無いか、ふさがれていました」と送る。

未読み込みのチャンクは `ensure_chunk` で読む。すでにメモリにあるか、外部生成が無効でその場で生成できたときはベッドを判定する。保存済みでまだ届いていないチャンクや、外部生成の完了を待っているチャンクは、この場では待てないのでベッドが無いものとして初期スポーンに出し、地点も消す。

## 保存とプロトコル

プレイヤーデータの保存は版 7。版 6 の 258 バイトのうしろに、リスポーン地点の有無を u8 で足す。0 なら地点なしで合計 259 バイト。1 なら足の座標を i32 三つ、ビッグエンディアンで足し、合計 271 バイト。版 1〜6 はリスポーン地点なしとして読む。ブラウザの OPFS と Durable Object は、この同じバイト列をそのまま保存して復元する。寝ている状態は書かない。

プロトコルは 32。C2S `StopSleeping`（タグ `0x14`、中身なし）。S2C `Sleeping`（タグ `0x1f`、`sleeping` を u8 の 0 か 1）。寝たときと起きたときに、本人にだけ送る。ほかのプレイヤーの寝ている姿は送らない。
