# チャット

同じワールドで、参加済みのプレイヤー全員に発言が届く。シングルプレイでも同じ仕組みで、自分の発言が表示される。

ポインターをロックしてプレイ中に T（設定で変更可能）または Enter を押すと入力欄が開く。入力中はポインターロックが外れ、移動などのゲーム操作を受け付けない。入力は Unicode のスカラー値で最大 256 文字。Enter で送信し、空白だけならそのまま閉じる。Esc は入力を破棄する。閉じるときにポインターロックの復帰を要求する。

発言は `<名前> 本文`、参加と退出は `名前 が参加しました`、`名前 が退出しました` と表示する。左下のホットバー上に表示し、行が届いてから 10 秒でフェードアウトが完了する。入力欄を開くと直近 50 行をスクロールできる。本文と名前はテキストとして表示する。

## プロトコル 24

`Hello` のプロトコル番号は 24。各文字列は UTF-8 のバイト長を VarInt で送り、その直後に UTF-8 のバイト列を置く。上限超過、不正な UTF-8、未知の `kind`、途中で切れたパケットはデコードエラーになる。

| 方向 | タグ | ペイロード |
| --- | --- | --- |
| C2S | `0x12` | `text`（最大 1024 バイト） |
| S2C | `0x13` | `kind u8`、`sender`（最大 64 バイト）、`text`（最大 1024 バイト） |

`kind` は 0 が発言、1 が参加、2 が退出。発言は送信者を含め、`Hello` を受理したすべてのクライアントに送る。参加と退出は、そのプレイヤー以外の参加済みクライアントに空の本文で送る。

サーバーは本文の前後の空白を取り除き、空の本文、制御文字を含む入力、256 Unicode スカラー値を超える本文を破棄する。死亡中のクライアントからの発言も受け付ける。接続ごとに最大 5 トークンから開始し、有効な発言 1 件につき 1 トークンを消費する。20 サーバー tick ごとに 1 トークンを上限まで補充し、残量がないときの発言は破棄する。通常の進行速度では 20 tick は 1 秒。

チャットの名前、発言、連投制限は接続中だけ扱う。ワールドの保存形式と状態ハッシュへの入力は従来どおり。

## 表示名

- ログイン済みのマルチプレイでは Better Auth の `user.name` を使う。ルーターはリクエストの `X-MC-Name` を取り除き、確定した名前を `encodeURIComponent` で符号化して WorldDO に渡す。WorldDO は復号してコアに渡す。メールアドレスは表示名の決定に使わない。
- ops 接続は `operator`、未ログインの開発用接続は `dev-` に接続 UUID の先頭 4 文字を付ける。
- シングルプレイは `あなた`。
- コアは名前から制御文字と前後の空白を取り除き、Unicode スカラー値で先頭 16 文字を使う。空の場合の表示名は `プレイヤー`。

プロトコル 25 では、ゾンビの近接攻撃による押し返しと Mob の燃焼状態を同期する。詳細は [押し返しと燃えている見た目](mobs.md#プロトコル-25) を参照。

プロトコル 26 では、爆心を `Explosion` で同期する。詳細は [爆発の仕上げ](mobs.md#プロトコル-26) を参照。

プロトコル 27 では、ほかのプレイヤーの名前と姿勢を `PlayerSpawn`、`PlayerMove`、`PlayerRemove` で同期する。詳細は [ほかのプレイヤー](entities.md#ほかのプレイヤープロトコル-27) を参照。

プロトコル 28 では、チャットに通知・動作・ささやきの種類を足し、コマンドを処理する。詳細は [コマンド](chat.md#コマンドプロトコル-28) を参照。

## コマンド（プロトコル 28）

`Hello` のプロトコル番号は 28。既存のチャットパケットを使い、次の `kind` を追加する。

| 値 | `kind` | `sender` | 表示 |
| --- | --- | --- | --- |
| 3 | `System` | 空文字列 | 本文のみを淡い黄色で表示する |
| 4 | `Emote` | 発言者の表示名 | `* 名前 本文` を斜体で表示する |
| 5 | `WhisperFrom` | 送り主の表示名 | `名前 からのささやき: 本文` を淡い紫の斜体で表示する |
| 6 | `WhisperTo` | 宛先の表示名 | `名前 へのささやき: 本文` を淡い紫の斜体で表示する |

各行は種類別の CSS クラスを持ち、半透明の黒背景に `textContent` で表示する。

サーバーは前後の空白を取り除いた入力が `/` で始まる場合、コマンドとして処理する。コマンド名の英字の大小は区別しない。引数の誤りや権限不足を含め、処理するコマンド 1 件につき通常の発言と同じ連投制限のトークンを 1 個消費する。コマンドの入力そのものは配信せず、`System` の結果とエラーは実行者だけに返す。各コマンドの配信先は次のとおり。

| コマンドと引数 | 権限 | 結果・エラー |
| --- | --- | --- |
| `/help` | 全員 | コマンドの一覧を `System` で 1 件ずつ表示する。operator には `/time` と `/seed` も表示する |
| `/list` | 全員 | 実行者も含め、`参加中 N 人: 名前, …` を `System` で表示する |
| `/me <本文>` | 全員 | 参加中の全員（実行者を含む）に `Emote` を送る。本文が空なら `使い方: /me <本文>` を返す |
| `/msg <名前> <本文>`（`/tell`、`/w` も同じ） | 全員 | 宛先に `WhisperFrom`、実行者に `WhisperTo` を送る。エラーは `プレイヤーが見つかりません`、`自分にはささやけません`、`本文を入力してください` |
| `/time set <day\|noon\|night\|midnight\|0〜23999>` | operator | 日内の時刻を設定し、`時刻を N にしました` と返す。引数が不正なら使い方を返す |
| `/time add <1〜24000>` | operator | 指定した tick 数だけ時刻を進め、`時刻を N にしました` と返す。引数が不正なら使い方を返す |
| `/seed` | operator | `シード: N` を返す |

権限が不足している場合は `このコマンドを使う権限がありません`、未知のコマンドには `不明なコマンドです。/help で一覧を表示します` と返す。

`/msg` は引数の先頭を、自分以外の参加中のプレイヤーの表示名と照合する。大小文字を区別し、名前の直後が空白か引数の末尾になる候補のうち最長のものを使う。表示名に空白があっても指定できる。同じ表示名の参加者が複数いれば、自分を除いた全員に送る。

`/time set` は `day_time` の日数（24,000 tick ごとの商）を保ち、その日の時刻（余り）を置き換える。`day` は 1,000、`noon` は 6,000、`night` は 13,000、`midnight` は 18,000。`/time add` は `day_time` に指定値を加え、翌日に繰り越せる。どちらも `game_time` に影響しない。実行結果は実行者に返し、ワールドの時刻は通常の時刻同期で参加者に伝える。

シングルプレイでは自分が operator になる。マルチプレイではワールドのメンバーの役割を使い、ops 接続と認証なしの開発用接続は operator になる。ルーターはリクエストの `X-MC-Role` を取り除き、確定した役割を設定して WorldDO に渡す。

メンバーの役割を変更すると、WorldDO の `setRole` が変更時刻と役割を記録し、接続中のプレイヤーにも反映する。役割変更と前後した古い参加要求には、ルーターでの認可時刻と記録した変更時刻を照合し、時計のずれを考慮して記録済みの役割を優先する。定期的なアクセス再確認では同じ接続とセッションかを確認し、問い合わせ開始後に `setRole` が役割の版を更新した場合は照会結果の役割を適用しない。

プレイ中に `/` キーを押すと、`/` を入れて末尾にカーソルを置いた状態で入力欄を開く。ほかの操作に割り当て済みの場合は既存の割り当てを優先する。入力欄の ↑／↓ で、そのページから送信した直近 50 件の発言とコマンドをたどれる。最新の送信より先へ ↓ で進むと、たどり始める前の入力に戻る。履歴はページのメモリに保持し、IME 変換中は矢印による履歴操作を行わない。

`tools/e2e.mjs` の `chatCommands()` は、新規のシングルプレイで `/` による入力開始、operator 用のヘルプ、夜への時刻変更、シード、不明なコマンド、入力履歴を確認する。新規の WebSocket ワールドに 2 ページで参加し、ささやきの送受信、動作の共有、参加人数を確認する。コマンドやささやきの本文が通常の発言として表示されないことと、ページエラーがないことも確認する。
