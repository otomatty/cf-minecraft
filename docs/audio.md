# 効果音と BGM

Web Audio API で波形を合成するクライアント側の機能です。音声ファイルは読み込みません。

## 構成

- `audio/world-audio.ts` はパケットの適用前後と、クライアントが描画に使う移動・採掘状態を観測します。
- `audio/events.ts` はイベントの判定、素材の分類、音量と定位の計算を行います。
- `audio/effects.ts` は発振器、フィルターを通したノイズ、音量エンベロープを組み合わせて効果音を作ります。ノイズのバッファは使い回し、再生オフセット、音の高さ、長さを少しずつ変えます。
- `audio/music.ts` は曲を組み立て、`audio/engine.ts` は再生、音量、同時発音数を管理します。素材、イベント、音量、曲の生成は host テストから確認できます。

最初のクリックやキー入力で `AudioContext` を作成または再開します。ページが非表示になるか BFCache に入ると、効果音を止めてコンテキストを一時停止します。ページが再び表示されると、BGM は続きから再開します。コンテキストを使えない環境でもゲームは動作します。

## イベントと音の対応

| イベント | 音と検出方法 |
| --- | --- |
| ブロック破壊・設置 | `BlockUpdate` 適用前後の素材に応じた割れる音・置く音。先にローカルで予測した編集は予測前の状態を使います。水や溶岩が流れて増減するセルや、作物の成長段階などの更新は省きます。 |
| 採掘中・足音 | 採掘中は素材に応じた小さな音を約 220 ms 間隔で鳴らします。地上の歩行は約 1.65 ブロックごとに足元の素材、水中の移動は同じ距離ごとに水音を使います。 |
| プレイヤー | `PlayerStatus` の体力低下で低く短い打音、満腹度上昇で咀嚼音、死亡への遷移で低く長い音を鳴らします。 |
| Mob | `MobHurt` は種類ごとに異なる周波数、波形、ノイズで表現します。最近被弾した Mob の `EntityRemove` ではさらに低く長い音を使います。 |
| アイテム | 近くで消えたアイテムや個数が減ったアイテムを、直後の持ち物の同種アイテムの増加と突き合わせ、短く上昇する音を鳴らします。 |
| 弓と矢 | プロトコル 23 の `ArrowSpawn` で `fresh` が 1 のときに弦と風を思わせる音を鳴らします。発射した tick にそのまま刺さった矢も対象です。`ArrowMove` の速度がゼロになったとき、または現在のサーバーで刺さった矢が描画用の速度を維持したときに、短い打音を鳴らします。飛行中の矢が消え、その直前の軌道に被弾した対象や消えた Mob がいた場合は命中音を鳴らします。 |
| クリーパー | 点火開始で高域のノイズを鳴らします。導火線が上限付近に達して消えた位置では、低いサイン波とフィルターをかけたノイズを重ねます。 |
| 画面 | ボタンやボタン表示のリンクの操作で小さなクリック音を鳴らします。 |

既存パケットの組み合わせから推定するため、被弾通知なしで消えた Mob の死亡や、矢の命中先を確認できない場合の命中音は省かれることがあります。

## 素材

ブロックレジストリの名前から分類します。

| 素材 | 主なブロックと音 |
| --- | --- |
| 石 | 石、丸石、鉱石、砂岩、黒曜石など。中高域のノイズと短い打音。 |
| 木 | 原木、板材、木のハーフブロック・階段・フェンス、作業台など。低めのノイズと三角波。 |
| 土と草 | 土、草ブロック、耕地。低く鈍い音。 |
| 砂と砂利 | 砂、砂利、雪。粒状のノイズ。 |
| ガラス | ガラス、氷。高く澄んだ音。 |
| 羊毛 | 羊毛。高域を抑えた柔らかい音。 |
| 葉と植物 | 葉、花、草、小麦。高域の短い擦れ音。 |
| 水 | 水源と流水。上昇するサイン波と水しぶきのノイズ。 |
| 溶岩 | 溶岩源と流れる溶岩。低く落ちる音とこもったノイズ。 |

## 位置と音量

ワールドの音は再生開始時のカメラを基準に、ヨーに応じたステレオ定位と三次元距離による減衰を付けます。距離による倍率は 0 ブロックで 1、16 ブロックで 0.5、32 ブロック以上で 0 です。最終的な倍率は、全体音量 × 効果音または音楽の音量 × 距離の倍率です。ボタン、プレイヤーの状態音、BGM は中央から鳴ります。同時に再生する効果音は最大 24 声で、新しい音を鳴らすときに上限に達していれば最も古い声から止めます。

## BGM

自作の短いフレーズをセッション中に生成します。昼はメジャー・ペンタトニック、夜は低いマイナー・ペンタトニックを使い、夜はテンポも落とします。曲の開始時に昼夜を判定し、サイン波と三角波をゆっくり立ち上げ、短いフィードバック付き遅延で残響を加えます。曲は約 1〜3 分で、その後に約 2〜5 分の無音を挟んで次の曲を生成します。音楽または全体の音量が 0 なら、再生中の曲を止め、新しい曲を生成しません。

## 設定と確認

ゲームメニューの「設定…」から「音量」タブを開きます。全体、効果音、音楽の音量をそれぞれ 0〜100% で調整できます。既定値は全体 80%、効果音 100%、音楽 60% です。値はキー割り当てなどと同じ `SETTINGS_KEY` に保存されます。古い設定には既定の音量を補います。

`window.__mc.stats().audio` の `state` に `running`、`suspended`、`unavailable` のいずれかが入り、`counts` には実際に開始した効果音の種類別回数、`bgm` には BGM の再生状態が入ります。
