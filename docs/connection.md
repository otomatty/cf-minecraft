# マルチプレイの切断と再接続

| 閉じるコード | 理由 | 自動再接続 | 画面の表示 |
| --- | --- | --- | --- |
| 1012 | サーバーの再起動 | する | サーバーが再起動しています。再接続しています(N回目)… |
| 1013 | ワールドが満員 | する | ワールドが満員です。空きを待って再接続しています(N回目)… |
| 4000 | 別の場所でログイン | しない | サーバーとの接続が切れました: 別の場所で同じアカウントが接続しました |
| 4001 | 参加の取り消し | しない | サーバーとの接続が切れました: このワールドへの参加が取り消されました |
| 4002 | パケットのレート超過 | しない | 操作が多すぎたため、サーバーから切断されました |
| 4003 | 不正なパケット | しない | 通信の内容が正しくないため、サーバーから切断されました |
| 4004 | プロトコルの版が不一致 | しない | ゲームのバージョンがサーバーと違います。ページを再読み込みしてください |
| その他 | 通信断など | する | サーバーとの接続が切れました。再接続しています(N回目)… |

WebSocket が開くとクライアントは Hello を送る。10 秒以内に Welcome が届かなければソケットを閉じ、「サーバーが応答しません。再接続しています(N回目)…」と表示する。再接続は指数バックオフで待ち、接続前に `/api/worlds/:world` で参加できることを確認する。確認が 401、403、404 を返したら打ち切る。Welcome を受け取ると再接続の回数をリセットする。

再デプロイや退避のあとも、同じログイン済みアカウントで同じワールドに再接続すると、最後に保存した位置とインベントリを引き継ぐ。自動保存は約5秒ごとに行う。

4004 を初めて受けたときは `sessionStorage` に記録してページを自動で再読み込みする。記録済みの場合やストレージが使えない場合は、表の文言を表示して止まる。Welcome が届いたら記録を消す。

## 再デプロイ時の版の混在（#27）

新しいサーバーに古いクライアントがつないだ場合、クライアントが 4004 に対応していれば、自動再読み込みで新しいクライアントを取り直せる。古いサーバーに新しいクライアントがつないだ場合は、Welcome の見張りで再接続を続け、古いインスタンスが止まるまで待つ。
