# 公式テクスチャのインストール

1. タイトル画面で Google アカウントにログインします。シングルプレイにもログインが必要です。開発モード（`DEBUG=1`）ではログインを省略できます。
2. 「テクスチャをインストール」で公式のリリースページを開き、最新版の Assets にある、名前が `-full.zip` で終わるファイルを保存します。ダウンロードすると Minecraft の使用許諾契約（EULA）に同意したことになります。[Bedrock Samples の最新版](https://github.com/Mojang/bedrock-samples/releases/latest)
3. 保存した ZIP をタイトル画面にドロップするか、「ファイルを選ぶ」から開きます。保存が終わるとテクスチャが適用され、メニューが表示されます。

タイトル画面の「入れ直す」、またはプレイ中の「設定」→「テクスチャ」→「別の ZIP に入れ替える」から更新できます。失敗したときは、それまでのパックを使い続けます。

使用するブロックとアイテムの画像とパックのバージョンは、このサイトの IndexedDB に保存します。テクスチャの保存にはサイトデータの保存権限が必要です。パックのデータはブラウザ内で処理し、外部に送信しません。サイトデータを消すと、次に遊ぶときにインストール画面が出ます。以前の形式で保存したパックも、最新版の手順でインストールし直してください。

## 対応する ZIP

- ZIP の直下、または直下の1つのフォルダーに `version.json` と `resource_pack/` が必要です。`version.json` の `latest.version` は3〜4個の数字をドットで区切った文字列で、`resource_pack/manifest.json` は Bedrock Samples の UUID を持つ必要があります。
- `resource_pack/textures/` の `terrain_texture.json` と `item_texture.json` を使い、ゲームに対応するブロック面とアイテムの PNG を取り出します。`-min.zip` には必要な画像がありません。
- PNG は最近傍で 16 × 16 に変換します。正方形のタイルを縦に並べた画像は先頭の1枚を使います。対応する PNG がない名前には内蔵素材を使います。

ZIP は 256 MiB、32,768 項目、宣言された展開サイズの合計は 512 MiB までです。使用する JSON は各 2 MiB、PNG は各 4 MiB・合計 32 MiB までです。画像の幅は 512 ピクセル、高さは 4,096 ピクセル、面積は 1,048,576 ピクセルまでです。読み出すファイルには無圧縮または Deflate 形式を使用します。

## 開発と検証

リポジトリのルートで WASM をビルドし、仮パックを書き出します。仮パックはレジストリの名前から生成した画像を使います。

```sh
pnpm build:wasm
node tools/fixture-pack.mjs /tmp/fixture-full.zip
pnpm --filter web dev
```

タイトル画面で生成した ZIP を選ぶと、開発モードでプレイできます。E2E もタイトル画面から仮パックをインストールします。
