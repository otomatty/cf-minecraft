# 公式テクスチャのインストール

1. タイトル画面で Google アカウントにログインします。シングルプレイにもログインが必要です。開発モード（`DEBUG=1`）ではログインを省略できます。
2. 「テクスチャをインストール」で公式のリリースページを開き、最新版の Assets にある、名前が `-full.zip` で終わるファイルを保存します。ダウンロードすると Minecraft の使用許諾契約（EULA）に同意したことになります。[Bedrock Samples の最新版](https://github.com/Mojang/bedrock-samples/releases/latest)
3. 保存した ZIP をタイトル画面にドロップするか、「ファイルを選ぶ」から開きます。保存が終わるとテクスチャが適用され、メニューが表示されます。

タイトル画面の「入れ直す」、またはプレイ中の「設定」→「テクスチャ」→「別の ZIP に入れ替える」から更新できます。失敗したときは、それまでのパックを使い続けます。

使用する画像とパックのバージョンは、このサイトの IndexedDB に保存します。テクスチャの保存にはサイトデータの保存権限が必要です。パックのデータはブラウザ内で処理し、外部に送信しません。サイトデータを消すと、次に遊ぶときにインストール画面が出ます。以前の形式で保存したパックも、最新版の手順でインストールし直してください。

## 対応する ZIP

- ZIP の直下、または直下の1つのフォルダーに `resource_pack/` が必要です。`manifest.json` の `header` には Bedrock Samples の UUID と、非負の整数3個の `min_engine_version` が必要です。`bedrock-samples-v…-full.zip` の版の先頭3要素が一致すればファイル名の版を表示し、プレビューの接尾辞も引き継ぎます。それ以外では `min_engine_version` を表示します。
- `resource_pack/textures/` の `terrain_texture.json` と `item_texture.json` を使い、ゲームに対応するブロック面とアイテムの画像を取り出します。画像を取得するには `-full.zip` を選びます。
- PNG を優先し、同じパスに PNG がなければカラーマップなしの32ビット TGA（非圧縮・RLE）を使います。画像の先頭の正方形を最近傍で 16 × 16 に変換します。水の縦並び画像は最大32コマを取り込み、元のコマ数に応じて繰り返します。草の側面はパックの土と草の重ね画像を合成し、バイオームの草色を使います。

ZIP は 256 MiB、32,768 項目、宣言された展開サイズの合計は 512 MiB までです。使用する JSON は各 2 MiB、画像は各 4 MiB・合計 32 MiB までです。画像の幅は 512 ピクセル、高さは 4,096 ピクセル、面積は 1,048,576 ピクセルまでです。読み出すファイルには無圧縮または Deflate 形式を使用します。

## 画像が見つからない場合

ゲームが使うブロックまたはアイテムの画像を1枚以上取り出せた場合は、残りの画像が欠けていてもインストールしてプレイできます。画像を収録していない `-min.zip` など、該当する画像を1枚も取り出せない ZIP はインストールできません。公式のリリースページで `-full.zip` を選び直してください。

タイトルのメニューと設定の「テクスチャ」に、見つからなかった画像の件数が表示されます。件数にはゲームが参照するブロック面・アイテム・ひび・空・HUD の画像キーを含みます。ブロックとアイテムの欠けは紫と黒の市松模様、HUD アイコンの欠けは単色の四角で表示します。採掘のひび、太陽・月・雲は、対応する画像がある場合に描画します。

動物・モンスター・プレイヤーのスキン、燃えているときの炎、爆発には、引き続きこのプロジェクトの自作画像を使います。スケルトンが持つ弓はパックのアイテム画像を使います。

## 開発と検証

リポジトリのルートで WASM をビルドし、仮パックを書き出します。仮パックはレジストリの名前から生成した画像を使います。ブロックやアイテムを追加するときは、公式パックの画像への対応付けを取り込み処理に足し、仮パックにも対応する画像を用意します。[取り込み処理](../apps/web/src/client/texture-pack.ts)・[仮パック](../apps/web/test/texture-pack-fixture.mjs)

```sh
pnpm build:wasm
node tools/fixture-pack.mjs /tmp/fixture-full.zip
pnpm --filter web dev
```

タイトル画面で生成した ZIP を選ぶと、開発モードでプレイできます。E2E もタイトル画面から仮パックをインストールします。

WASM のビルド後、手元の公式 ZIP でゲームが使う全テクスチャ名が解決できるか確認できます。

```sh
node tools/check-official-pack.mjs /path/to/bedrock-samples-v1.26.60.5-full.zip
```

取り込めるパックは版、解決件数、未解決の名前を表示します。取り込みに失敗した場合や未解決の名前がある場合は終了コード 1 を返します。PNG は取り込み時の構造検査まで行い、TGA は実際にデコードします。公式 ZIP はローカルで指定し、この検査は CI では実行しません。
