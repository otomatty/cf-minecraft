# プレイヤーごとのテクスチャパック

ゲームに参加し、Esc で「設定」→「テクスチャ」を開きます。使用権限のある Bedrock リソースパックの ZIP または `.mcpack` を選び、読み込めた枚数を確認して「適用」を押します。初めて遊ぶブラウザでは自作の標準素材を使います。公式サンプルを使う場合は配布元で利用条件を確認して、プレイヤー自身で取得してください。[Bedrock Samples のリリース](https://github.com/Mojang/bedrock-samples/releases) · [配布条件](https://github.com/Mojang/bedrock-samples/blob/main/LICENSE.md)

ワールドのブロック、ドロップ、インベントリ、ホットバーに即時反映します。選んだファイル名と使用するタイルの画素、適用状態をこのサイトの IndexedDB に保存するので、同じブラウザでは再接続後も有効です。「標準素材に戻す」で一時解除し、「適用」で再び使用できます。「パックを削除」で保存したデータを消去します。パックの内容と選択状態は端末内で扱い、マルチプレイの相手は自分の設定で同じワールドを表示します。

## 対応するファイル

- パック直下または親フォルダーの下にある1つの `textures/` を認識します。`resource_pack/textures/` を含む Bedrock Samples の ZIP も選べます。
- ブロックは `textures/terrain_texture.json`、アイテムは `textures/item_texture.json` の `texture_data` を読みます。`textures` の文字列、`path` を持つオブジェクト、その配列に対応します。JSON 内のコメントも扱えます。パスはパックルートからの `textures/` 相対で、末尾の `.png` は省略できます。
- ゲームにある面・アイテムのみを対応づけます。例えば `stone` は石の面、`grass_top` は草ブロックの上面、`apple` はリンゴです。配列は通常先頭を使用し、道具・小麦・耕地・葉・バケツなどはゲームに対応する種類・段階を選びます。対応する定義がない場合は `textures/blocks/stone.png` や `textures/items/apple.png` などの既定のファイル名を探します。
- PNG は最近傍で 16 × 16 に変換します。正方形のタイルを縦に並べた画像は先頭の1枚を使います。欠けている画像、TGA などの非対応素材には標準の絵を使います。対象が0枚の場合や対象データが壊れている場合は、適用中のパックを維持します。
- モブ・プレイヤーのスキン、モデル、HUD、アニメーション、PBR、色指定・重み付きバリエーションは対象外です。ゲーム本体の抽出、外部参照の取得、パックの配信や同期は行いません。

## 読み込み上限

ZIP は 256 MiB、32,768 項目、宣言された展開サイズの合計は 512 MiB までです。使用する JSON は各 2 MiB、PNG は各 4 MiB・合計 32 MiB まで。画像の幅は 512 ピクセル、高さは 4,096 ピクセル、面積は 1,048,576 ピクセルまでです。対象ファイルは無圧縮または Deflate 形式を使ってください。
