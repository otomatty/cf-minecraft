# 空・昼夜・描画距離フォグ

`client/sky.ts` は DOM とシミュレーションに依存しない表示用の計算。
Java Edition の従来の晴天の昼夜モデルを対象とし、逆コンパイルしたコードや
既存ゲームの画像は使用しない。新しい版の環境属性・天候・バイオーム別の色は対象外。

## 出典と再現範囲

- タスク #15 に提示された公開の天体角の式をそのまま数式として実装した。
  1日24,000 tick、0=06:00、6,000=正午、18,000=真夜中という時刻系に従う。
  昼夜の時刻・天体の動きの説明: [Daylight cycle](https://minecraft.wiki/w/Daylight_cycle)。
- [公式 Snapshot 25w45a](https://feedback.minecraft.net/hc/en-us/articles/41225261004941-Minecraft-Java-Edition-Snapshot-25w45a)
  は星の通常の夜間輝度を0.5、非表示を0と定義している。
- [公式 1.18.1](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-18-1)
  の円筒化に合わせる。[公式 Snapshot 25w19a](https://www.minecraft.net/en-us/article/minecraft-snapshot-25w19a)
  は描画距離フォグを円筒距離、環境フォグを球距離と明記している。
  この実装は前者のみ。水中・溶岩・天候等の環境フォグは実装しない。
- [Moon](https://minecraft.wiki/w/Moon) の8日周期、太陽と反対側の位置に合わせる。

以下の色・薄明・星の補間は、従来の晴天の見え方を再現する表示用の式。
公式リリースノートが各補間式・RGB係数まで規定しているわけではない。
空の基本色、最低照度、帯の広さ、天体の大きさ、雲と星の模様は本実装の選択であり、
本家の全バイオーム・全バージョンと画素単位で一致するものではない。

## 式

`clamp(x)=max(0,min(1,x))`、`frac(x)=x-floor(x)`、`t=dayTime+部分tick` とする。

```
f = frac(t / 24000 - 0.25)
angle = f + (1 - (cos(f * π) + 1) / 2 - f) / 3
h = cos(angle * 2π)
B = clamp(2h + 0.5)
skyRGB = (120/255, 167/255, 1.0) * B
stars = clamp(1 - (2h + 0.25))² * 0.5
moonPhase = floor(t / 24000) mod 8
skylight = 0.18 + 0.82 * clamp(2h + 0.2)
```

太陽の方向は `(-sin(angle*2π), cos(angle*2π), 0)`、月はその逆。
東(+X)から昇り、西(-X)に沈む。正午は太陽が真上、真夜中は月が真上。
月相は0=満月、1=欠け始め、2=下弦、3=細い月、4=新月、5〜7=満ちていく月。

`abs(h)<=0.4` のときだけ、地平線に日の出・日の入りの帯を出す。

```
u = h / 0.4 * 0.5 + 0.5
bandRGB = (0.7 + 0.3u, 0.2 + 0.7u², 0.2)
bandStrength = (1 - (1 - sin(uπ)) * 0.99)²
```

帯の画面上の強さは `bandStrength * exp(-12*abs(ray.y))` に、
太陽側の水平視線成分の正の部分の二乗を掛ける。
空と地平線のフォグ色は `smoothstep(0,0.45,ray.y)` で補間する。

```
baseFog = (192/255*(0.94B+0.06), 216/255*(0.94B+0.06), 0.91B+0.09)
skyMix = 1 - (0.25 + 0.75*clamp(viewChunks/32))^0.25
fogRGB = mix(baseFog, skyRGB, skyMix)
distance = max(length(cameraRelative.xz), abs(cameraRelative.y))
fogStart = viewChunks * 16 * 0.75
fogEnd = viewChunks * 16
fog = smoothstep(fogStart, fogEnd, distance)
```

距離は頂点間で距離そのものを補間せず、フラグメントのカメラ相対座標から計算する。
地形色には `skylight` を掛ける。夜間の最低値0.18は視認性のための仮の照度であり、
光源エンジン #14 でブロック単位の光量に置き換える。

## 描画と時刻同期

空は全画面三角形から視線を復元して描画する。太陽と月は天体方向に垂直な四角形と
視線の交点を求め、オリジナルの16×16手続きピクセル絵を最近傍サンプリングする。
月の明暗境界は球面の法線と8方向の照明の内積で生成し、各相で絵を変える。
太陽と月は `color += textureRGB * textureAlpha * 地平線の可視係数` の加算合成。
空の色を置き換えず光を足すため、昼の空の上でも太陽の内側が暗くならない。
出力先の0〜1へのクランプで明るい部分は白になる。
星は球面を512×256セルに分け、固定シード10842の整数ハッシュで点を散らす。
天体角とともに回転し、星の輝度に応じて夜だけ見える。星もRGBの加算で空を暗くしない。

雲はY=192の両面平面。周期的な波を閾値化したオリジナル模様を256ブロック周期で
繰り返し、1 tickに0.015ブロック（毎秒0.3ブロック）流す。
昼は白、夜は明るさ0.16の灰色とし、`0.16 + 0.84B` で昼夜を補間する。
模様の不透明度は210/255（約0.82）。雲専用の円筒フォグは
`end=max(256, viewChunks*16*2)`、`start=end*0.65` とする。
上記と同じ円筒距離で `fog=smoothstep(start,end,distance)` を計算し、
`alpha=textureAlpha*(1-fog)` で遠方だけ背景へ溶け込ませる。
RGBをさらにフォグ色へ寄せる二重の減衰は行わない。
高さ110から真上の雲を見る場合の距離82は、最小の開始距離166.4より近いため減衰しない。
雲平面はカメラを中心に各軸±endまで広げ、遠クリップ面もendの2倍以上に設定する。

描画順は、空 → 星・太陽・月（同じ空シェーダー内で加算）→ 地形 → 雲。
空は深度を書かず、地形は深度テストと書込みを行う。
雲は両面描画で地形の深度を `less-equal` でテストし、深度を書かず通常の
`src-alpha / one-minus-src-alpha` で合成するため、手前の地形は雲を遮る。
座標はカメラ相対、
模様の原点は周期で剰余を取り、遠方での浮動小数点精度低下を避ける。

時刻パケットは1秒ごとなので、最後の受信からのミリ秒/50を `core.dayTime` に加える。
部分tickは小数を含み0〜20に制限する。切断中は加算しない。
フレームごとの推定値は描画だけに渡し、コア・HUD・autopilot・既存の操作APIは変更しない。
`stats().skyBrightness` は空の係数B（0〜1）を返す。

ローカル開始時に `?time=<非負の安全な整数tick>` を渡すと、保存済み時刻の読込後、
接続前に統合サーバーの `setTime(gameTime, dayTime)` で時刻を設定する。
既存ワールドでも指定値を適用し、通常の保存対象となる。gameTimeは維持する。
不正な値は無視し、マルチプレイにはパラメーターを送らない。

## 検証

`sky.test.ts` を `test:host` に含める。正午・真夜中、角度の周期と連続性、
薄明、月相、全周期の値域、補間、URLの入力、手続き絵の再現性を検査する。
E2Eでは同じシード・固定カメラで `?time=6000` と `?time=18000` を開き、
既存の空白フレーム検査と同じスクリーンショット格子で平均輝度を比較する。
真夜中の画面の輝度が正午の65%未満となること、空の係数、GPUエラーを検査する。
