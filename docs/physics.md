# プレイヤー物理

`crates/physics` は I/O やワールド生成に依存しない20TPSの予測用物理。
次の PR でサーバーからも利用する。今回の PR はプロトコル・サーバーの台本を変更しない。
逆コンパイルしたソースコードは使わず、下記の公開仕様と issue #13 の指定式から実装した。
Java 版の通常ブロック上での移動を対象とし、バージョンごとの追加属性、液体、特殊な摩擦、
泳ぎ、姿勢による体積変更、エンティティ同士の衝突は対象外。

## 座標と数値

- 位置・速度・AABB は `f64`。位置は足元の中心、速度はブロック/tick。
- 立位の幅 `0.6f`、高さ `1.8f`、段差 `0.6f` は Java float 相当の `f32` から `f64` に拡張。
  目の高さは1.62。スニーク中もこの PR の当たり判定は立位のまま。
- yaw は `f32` の度数。0度は +Z、90度は -X。右入力は正。
  `yaw * (PI_f32 / 180f)` を `jmath::sin_table::{sin, cos}` に渡す。
- 入力、加速、水平摩擦、正規化は `f32`。算出した加速を `f64` の速度へ加算。
  重力は `0.08_f64`、鉛直抗力は `0.98_f32 as f64`、飛行鉛直抗力は `0.6_f64`。
  平方根は IEEE 754 の `sqrt` を使用し、libm の三角関数・HashMap・FMA は使用しない。

## 1 tick の式と順序

1. 各軸で絶対値0.003未満の速度を0にする。
2. 接地中にジャンプ入力があれば `vy = 0.42f`。ダッシュジャンプは
   `vx -= sin(yaw) * 0.2f`、`vz += cos(yaw) * 0.2f`。
   長押し時の再ジャンプ間隔は10 tick、離すと待ち時間を解除する。
3. 前後・左右の入力をそれぞれ [-1, 1] に制限し、歩行スニーク中は0.3倍、常に0.98倍する。
   長さが1を超える場合は正規化する。そのため斜めは直進の最大1/0.98倍になる。
4. 地上の水平摩擦 `q = 0.6f * 0.91f`、空中は `q = 0.91f`。
   地上の加速 `a = movement_speed * (0.16277136f / (q*q*q))`。
   `movement_speed` は歩行0.1f、ダッシュは `f32(0.1_f64 * 1.3)`。
   空中は0.02f、ダッシュ中は0.026f。スニーク中の歩行ではダッシュを解除する。
5. 加速済み入力を `s`（右）、`f`（前）とすると、
   `vx += -s*cos(yaw) - f*sin(yaw)`、`vz += f*cos(yaw) - s*sin(yaw)`。
6. スニーク接地中は足元から0.6下げたAABBに支持があるか調べる。
   X、Z、XZの順に、支持がなくなる移動量を0.05ずつ0へ近づける。
7. 速度分の移動を **Y → X → Z** の順にブロックAABBで切り詰める。
   移動前後を覆う領域を走査するので、1 tickでブロック幅以上を進んでも壁を抜けない。
   接触面だけの一致は重なりとみなさず、阻止された軸の速度を0にする。
8. 地上または着地する移動が水平に阻止された場合、0.6上昇、X/Z移動、下降の別経路を試す。
   天井で上昇量を制限し、水平距離が元の経路を超える場合だけ採用する。
   下降が阻止されたとき接地とする。1.0の段差はジャンプなしでは上れない。
9. 移動後に `vx *= q`、`vz *= q`、`vy = (vy - 0.08) * 0.98f`。

地上の直進加速はおよそ0.098で、終端での移動距離は `0.098 / (1-q)`、
およそ0.21585ブロック/tick = 4.317 m/s（ダッシュ5.612 m/s）。
保存される速度は移動後の抗力適用済みなので、これより小さい。
ジャンプの最高到達点はおよそ1.2522。

## クリエイティブ飛行とクライアント

飛行中は重力を使わず、水平加速は0.05f（ダッシュ0.1f）、水平抗力0.91f。
ジャンプ/下降入力に対して `vy += direction * 0.05f * 3f`、移動後に `vy *= 0.6`。
直進の終端速度はおよそ10.889 m/s（ダッシュ21.778 m/s）、鉛直は7.5 m/s。
飛行中も同じAABB衝突を使う。飛行中にスニークを押すと下降し、端の保護は使わない。

開始時は飛行で速度0。ジャンプの押し始め2回が7シミュレーションtick以内なら飛行を切り替える。
ブラウザのキーリピートは数えず、短い押下も次のtickへ保持する。
体がブロックと重なる場合・未受信チャンク内では歩行への切り替えを拒否し、飛行を維持する。
この PR では着地による自動飛行解除をせず、明示的な切り替えのみとする。
未受信チャンクは固体として扱う。現行ブロックレジストリは空気以外すべて完全な立方体である。
トレイトはブロック内に収まる任意の単一AABBを返せるため、0.5段差もテストできる。

WASM ABI はリセット、飛行切り替え、1 tick更新の3関数。
更新結果は足元xyz・速度xyz（6個のf64 LE）、接地・飛行（2個のu8）。
ブラウザは50msごとに物理を進め、前回と今回の足元座標を残余時間/50msで線形補間して描画する。
カメラだけ目の高さを加え、HUDと送信座標は足元を使う。
既存のフレーム時間上限100msを維持し、バックグラウンド復帰時に大量の追いつき更新を行わない。
autopilotは従来の軌道計算を維持。`window.__mc.setCamera` は速度と補間履歴もリセットする。

## 出典と検証

公開仕様の参照項目（2026-11-14確認）:

- [Minecraft Wiki: Walking — Usage](https://minecraft.wiki/w/Walking#Usage): 通常歩行4.317ブロック/秒。
- [Minecraft Wiki: Transportation — Motion](https://minecraft.wiki/w/Transportation#Motion): 地上・空中の移動、摩擦と抗力、重力の漸化式。
- [Minecraft Wiki: Jumping — Jump height](https://minecraft.wiki/w/Jump#Jump_height): 初速0.42、最高到達点1.2522。
- [Minecraft Wiki: Sprinting](https://minecraft.wiki/w/Sprinting): 歩行速度の30%増加、ダッシュジャンプ。
- [Minecraft Wiki: Sneaking](https://minecraft.wiki/w/Sneaking): 入力減速、ブロック端からの落下防止。
- [Minecraft Wiki: Flying — Controls / Speed](https://minecraft.wiki/w/Flying): ジャンプの2回押し、上昇/下降、慣性、ダッシュ飛行。
- [Minecraft Wiki: Player](https://minecraft.wiki/w/Player): プレイヤーの立位寸法。

Wikiの近似速度や現行バージョンの記述には差があるため、この PR の数値基準は issue #13 に指定された
0.16277136、Y/X/Z順序、0.6の段差、7 tickの入力窓とする。

`crates/physics/tests/movement.rs` はジャンプ、終端速度、斜め、壁、壁沿い移動、
高速移動、0.5/0.6/1.0段差、低い天井、端と角のスニーク、飛行、yawを検証する。
`tests/trajectory.csv` は48 tickの独立した一次元漸化式で計算した固定データ。
床y=0、yaw=0、初期位置(0.5,0,0.5)、接地、初期vy=-0.08*f32(0.98)とし、
f32演算の各段階をbinary32へ丸め、8 tick目にジャンプ、24 tick目からダッシュ、28 tick目にダッシュジャンプする。
ネイティブと `apps/web/src/client/physics.test.ts` のWASMが同じデータを照合する。
`tests/flight.csv` は36 tickの飛行の固定データで、非直角のyaw（123.4度、-137.25度など）、
斜め入力、ダッシュ、上昇/下降、入力を離した後の慣性も両ホストで照合する。
