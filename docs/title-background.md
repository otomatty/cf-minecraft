# タイトル背景の描画

タイトル画面は UI を先に表示し、その後で WebGPU の描画コードと WASM を読み込む。昼（6000 tick）に固定し、パックが無いときは空のグラデーションだけを描く。ブラウザの IndexedDB に保存したパックはログイン前から使用する。インストールや「入れ直す」の完了時は、開いているページで描画に反映する。

Terrain のシードは `2026`、カメラの水平座標は `(-432.5, 1864.5)`。草の丘とオークの木立があり、北から東にかけて水辺が開ける。足元の列の最上段から8ブロック上の `y=74` にカメラを置く。水平角205°、下向き12°から180秒で1周する。設定で「視差効果を減らす」を選んでいる場合は初期角度の静止画になる。地形を描くときだけ、文字の背後に上下の陰を重ねる。

生成データでは、半径64ブロックの地表の76.7%が草ブロック、12.8%が水面。オークの幹は21本あり、うち8本は32ブロック以内にある。陸地の高低差は12ブロックで、ブロックの上面は24ブロック以内で最高 `y=72`、24〜64ブロックで最高 `y=75`。カメラの周囲2ブロックは空気で、これらの条件はホストテストで検証する。

生成ワーカーが `server.wasm` の `gen_chunk` で、カメラのチャンク `(-28, 116)` から半径6チャンクの円内（113チャンク）を近い順に生成する。生成したチャンクをメモリ内で既存の `ChunkData` に包んでクライアント WASM に渡し、照明・メッシュ・バイオーム色の処理はプレイ画面と同じものを使う。サーバー接続、OPFS への書き込み、シミュレーションは行わない。ワーカー間の受け渡しには転送可能なバッファを使うため、タイトル画面に COEP は不要。

非表示タブでは描画を止め、DPR の上限は2とする。ページを離れるときはワーカーを終了し GPU デバイスを解放する。BFCache から戻ったときは保存済みパックを読み直し、背景を再作成する。WebGPU を利用できない場合やデバイスを失った場合は、キャンバスと陰を隠して単色の空 `#9cc2ef` を表示する。
